# ADR-0001: Record architecture decisions

**Status:** accepted

## Context

This project is a portfolio piece. The reasoning behind its structure is part
of what it is meant to demonstrate, and that reasoning is invisible in the code
itself.

## Decision

Record every significant architectural decision as a short numbered file here.

## Consequences

A reviewer can read the decisions in ten minutes without reverse-engineering
them from source. Agents working on the repo have a durable record of what was
already settled and why.
